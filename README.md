# Pusz Planer — Planer Oliwki

Planer nauki biologii i chemii na Windows 10/11 (64-bit).

## Pobieranie

Gotowe instalatory znajdują się w [Releases](../../releases). Pobierz plik `Planer-Oliwki-Setup-….exe`. Pliki `latest.yml` i `.blockmap` są przeznaczone dla aktualizatora.

## Funkcje

- 34 tygodnie, zadania na poszczególne dni i zadania ogólne.
- Notatki, zdjęcia, błędy i powtórki.
- Kolekcja guzików, pluszaków i zwierzaków.
- Pierwsze dwa tygodnie guzików zaliczone na start.
- Aktualizacje wymagające zgody na pobranie oraz instalację.

## Dane i kopie

Wpisy i kolekcja są przechowywane lokalnie; nie są wysyłane do tego repozytorium. Przed przejściem z wersji przenośnej zapisz kopię JSON w ustawieniach i zamknij stary planer. Po instalacji korzystaj z nowego skrótu. Zachowaj kopię bezpieczeństwa.

Aplikacja nie ma podpisu cyfrowego wydawcy. Windows może wyświetlić ostrzeżenie.
